# 하드웨어 배선 및 핀맵

Raspberry Pi 4(4GB)와 ESP32 기반 핸즈프리 자동문 프로젝트의 현재 배선 상태와 추후 확장 핀맵을 정리한 문서입니다.

- **현재 구현 완료:** ESP32, SG90 서보모터, HC-SR04 초음파 센서, TCRT5000 적외선 센서, MB102 전원 분리 배선
- **추후 추가 예정:** HLK-LD2450 레이더, INA226 전류 센서, 리드 스위치, 5V 능동 부저, 상태 LED

## 1. 시스템 및 전원 구성

- **Raspberry Pi 4 (4GB):** 웹캠 영상 기반 AI 판단 후 USB 시리얼(`115200 bps`)로 제어 명령(`OPEN`, `CLOSE`, `HOLD`, `ALERT`) 송신
- **ESP32-WROOM-32 (38핀 DevKitC):** 센서 값 수집, 장애물 안전 로직 처리, 서보 PWM 및 경고 장치 제어 (`3.3V` 로직)
- **브레드보드:** 830홀 브레드보드 2개를 결합해 ESP32 양쪽 핀을 모두 확보

서보모터 기동 시 순간 전류로 ESP32가 리셋(Brownout)되는 것을 막기 위해 로직 전원과 구동 전원을 분리하고, 모든 `GND`를 하나로 묶었습니다.

| 전원 라인 | 공급원 | 연결 대상 | 비고 |
| :--- | :--- | :--- | :--- |
| 로직 / 통신 | RPi 4 USB (테스트 시 PC USB) | ESP32 Micro-USB | 시리얼 통신 겸용 (`VIN` 핀 미연결) |
| 외부 `5V` (하단) | MB102 + 9V 1A 어댑터 | SG90, HC-SR04 | 중앙 레일 단절 구간(30번 열 부근) 점퍼 연결 |
| 외부 `3.3V` (상단) | MB102 (`3.3V` 점퍼) | TCRT5000 | 출력 신호를 `3.3V`로 맞춰 GPIO 보호 |
| 공통 `GND` | 전체 통합 | ESP32, MB102, 서보, 센서 | 기준 전위 일치용 |

## 2. ESP32 핀맵

### 현재 배선 완료

| 부품 | 핀 | ESP32 GPIO | 모드 | 메모 |
| :--- | :--- | :--- | :--- | :--- |
| **TCRT5000** | `DO` | `GPIO 4` | `INPUT_PULLUP` | `3.3V` 인가, 장애물 감지 시 `LOW` |
| **HC-SR04** | `TRIG` | `GPIO 23` | `OUTPUT` | 부팅 시 신호 튐 방지를 위해 `GPIO 5`에서 변경 |
| **HC-SR04** | `ECHO` | `GPIO 19` | `INPUT` | `1kΩ` 저항 3개로 `5V → 3.33V` 분압 연결 |
| **SG90** | `PWM` | `GPIO 18` | `PWM (50Hz)` | 전원 외부 `5V`, 신호선만 ESP32 직결 |

### 추후 확장 예정

`UART2`와 `I2C` 기본 핀은 충돌을 피하기 위해 미리 비워두었습니다.

| 부품 | 인터페이스 / 역할 | 예정 GPIO | 전원 | 메모 |
| :--- | :--- | :--- | :--- | :--- |
| **HLK-LD2450** | `UART2` (사람 감지) | `16(RX2)` / `17(TX2)` | `5V` | `256000 bps`, ESP32 RX ↔ 레이더 TX 교차 연결 (`3.3V` 로직 지원) |
| **INA226** | `I2C` (과전류/끼임 감지) | `21(SDA)` / `22(SCL)` | `3.3V` | 서보 전원 라인에 직렬 연결해 스톨 전류 측정 |
| **N/O 리드 스위치** | 문 완전 닫힘 감지 | 미정 | - | `INPUT_PULLUP` + 반대쪽 `GND` (유리관 파손 주의) |
| **5V 능동 부저** | `ALERT 2` 경고음 | 미정 | `5V` | 정격 `30mA` → `2N2222A` + `1N4148` 스위칭 회로 사용 예정 |
| **3색/단색 LED** | `ALERT 1/2` 표시 | 미정 | `3.3V` | 전류 제한 저항 직렬 연결 |

## 3. 적용된 보호 회로

### HC-SR04 `ECHO` 전압 분압 (`5V → 3.33V`)

ESP32 GPIO 허용 입력 전압(`3.6V`) 초과를 막기 위해 보유 중인 `1kΩ` 저항 3개를 `1kΩ : 2kΩ` 비율로 구성했습니다. (`5V * 2kΩ / 3kΩ ≈ 3.33V`)

```text
HC-SR04 ECHO (5V) ── [1kΩ] ──┬── [1kΩ] ── [1kΩ] ── GND
                             │
                       ESP32 GPIO 19 (3.33V)
```

## 4. 추후 적용 예정 회로 (미장착)

부품은 확보해 두었으며, 기능 확장 및 안정화 단계에서 추가할 예정입니다.

### 서보 전원 버퍼 커패시터

모터 기동 시 전압 강하와 PWM 노이즈가 발생하면 서보 전원 단자 인접 `5V`–`GND` 사이에 병렬 추가 예정입니다.

- `470µF (25V)` 전해 커패시터: 순간 전류 버퍼 (`+` 긴 다리 → `5V`, `-` 띠 표시 → `GND`)
- `0.1µF (50V)` 세라믹 커패시터: 고주파 노이즈 바이패스 (극성 없음)

### 5V 능동 부저 스위칭 회로

`5V` 능동 부저(최대 `30mA`)는 ESP32 GPIO 권장 전류(`12mA`)를 넘고 코일 역기전력이 발생하므로, NPN 트랜지스터로 Low-side 스위칭을 구성합니다.

- 부저 `+` → 외부 `5V` 레일
- 부저 `-` → `2N2222A` Collector (`1N4148` 다이오드 역방향 병렬 연결, 띠 방향이 `5V` 쪽)
- `2N2222A` Emitter → 공통 `GND`
- `2N2222A` Base → `1kΩ` 저항 → ESP32 제어 GPIO

## 5. 배선 참고 사항

- **전원 이중 인가 금지:** USB 연결 상태에서 외부 `5V`를 ESP32의 `VIN`/`5V` 핀에 같이 꽂지 않음
- **브레드보드 전원 단절:** 830홀 보드 중앙(30번 열 부근)에서 전원 레일이 끊어져 있어 좌우 레일을 점퍼선으로 연결함
- **핀 확장 시 회피 대상:**
  - 사용 금지: `GPIO 1, 3` (USB 시리얼), `GPIO 6~11` (내부 SPI 플래시)
  - 스트래핑 핀(가급적 회피): `GPIO 0, 2, 5, 12, 15`
  - 입력 전용(출력 및 `INPUT_PULLUP` 불가): `GPIO 34, 35, 36, 39`
